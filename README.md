# Los Prompteros Project

Deliverables for **Los Prompteros** — AgentSprint (ReshapeX AI-agent hackathon, Medellín).

Two self-contained HTML reports. No build step, no dependencies — open either file in any browser (they adapt to light/dark and have a theme toggle):

- **`brand-data-recon.html`** — the 21 AgentSprint brands ranked by how much *public* data each exposes for building a grounded AI agent (sortable heatmap + per-brand material breakdown).
- **`7-buildable-ideas.html`** — seven buildable, non-Q&A agent project ideas, each with two-depth implementation detail, a live judge-verification protocol, and a checklist of the tools it needs marked with the ones verified working.
