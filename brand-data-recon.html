01

What this is & how to read it

A scouting report for AgentSprint. It ranks all 21 eligible brands by one thing only: how much genuinely public data each exposes for an AI agent to ground on. It doesn't judge the brands as businesses — only as data sources for an agent. More real, reachable, machine-readable data means less of your morning spent hunting for something to build on, and a higher place here.

The five material groups — the scored columns. Weight = how much the group counts toward Overall for a grounded agent.

Developer & Integration ×0.95
Public APIs, dev portals, SDKs, device-description files — live, callable data. The gold standard for a tool-using agent.
Product & Commerce Data ×0.92
The catalog itself — listings, SKUs, prices, availability, product feeds. The entity backbone.
Technical Documentation ×0.88
Datasheets, manuals, spec sheets, CAD, certifications — deep per-product ground truth.
Knowledge & Support ×0.68
FAQs, troubleshooting, how-to guides, warranty/returns — real-world usage and fixes.
Corporate & Reference ×0.22
Annual/ESG/investor/press. Marginal for product grounding — kept, but deliberately weighted low.

The five evaluation axes — every group's 0–5 score is built by scoring the brand's material on these.

Volume & Coverage
How much material exists, and how much of the product line it actually covers.
Accessibility
Reachable with no login, paywall, or bot-blocking — directly fetchable by your code.
Machine-Readability
How easily an agent parses it: clean JSON/API vs. messy PDF or JS-only pages.
Depth & Richness
How much real, decision-grade detail is there once ingested.
Freshness
How current and actively maintained the material is.
Reading the numbers Each brand scores 0–5 per group; those combine, weighted, into one Overall /5. Scores are relative within these 21 brands, not absolute measures of volume. Higher = more real data to build on. Sort by any column to re-rank — Developer for a live API to call, Technical for datasheets to RAG over — and click any row to jump to that brand's full breakdown.

04

How this was built & scored

A fleet of agents mapped each brand's public footprint (normal browsing plus search-operator probing of PDFs, sitemaps, open directories and developer subdomains). Findings were classified into the smallest set of groups that still separates the brands, then one calibrated judge per group scored all 21.

Why five groups, not six or ten

Caveats. Scores are relative rankings within these 21 brands, from public sources only — not a measure of absolute data volume. Non-US and Spanish/Chinese-language sites (the Colombian retailers, TECO) were harder to index and carry lower recon confidence, so their scores are likely conservative. Access flags reflect what was reachable without login at recon time and can change. Verify any specific resource before you build on it.
